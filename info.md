# iTAG Tracker для Home Assistant

Отслеживайте ваши iTAG брелоки прямо в Home Assistant.

## 🚀 Быстрый старт

1. Установите интеграцию через HACS
2. Перезапустите Home Assistant
3. Добавьте iTAG через "Устройства и сервисы"
4. Введите MAC-адрес вашего брелока
5. Готово!

## ✨ Что вы получите

- **Сенсор батареи** - знайте, когда пора менять элемент питания
- **Детектор кнопки** - используйте iTAG как беспроводную кнопку для автоматизаций
- **Мониторинг сигнала** - отслеживайте RSSI для определения расстояния
- **Управление звуком** - заставьте брелок пищать для поиска

## 💡 Идеи автоматизаций

- Нажал на брелок - включился свет
- Вышел из дома с брелком - автоматически включилась сигнализация
- Потерял ключи - спроси у Алисы "где ключи?" и брелок запищит
- Батарея села - получи уведомление в Telegram

## 📱 Поддерживаемые устройства

Любые BLE-брелоки iTAG:
- iTAG Pro
- Smart iTAG
- Клоны AirTag
- Дешевые трекеры с AliExpress
